# 新增软件（新增安装任务）指南

给自部署的 AutoInstall 后端加一款新软件，本质就三件事：**准备安装包目录 → 建一条任务 → 写好脚本**。
客户端只认"任务"，不认软件厂商，所以商业软件、开源工具、绿色版小工具、内部系统，加法完全一样。

---

## 一、三条路，按熟练度选

| 方式 | 适用 | 怎么做 |
|---|---|---|
| **A. 管理台手填** | 偶尔加、脚本不长 | `http://YOUR_HOST/admin` → 安装任务 → `+ 新建任务` |
| **B. 工具生成（推荐）** | 长期维护、要算 MD5 | `tools/new_task.py`：自动算校验值、校验语法、一键推送 |
| **C. 直接调 API** | 接自己的发布流水线 | `POST /admin/api/task`，头 `X-Token: 口令` |

---

## 二、安装包目录长什么样

客户端是**按目录名**认包的：它在 **exe 所在目录**下找与 `appPackageName` 同名的子目录。

```
D:\装机包\                              ← 客户端 exe 放这里
├── AutoInstall_YOUR_HOST.exe
├── MyApp_1.0\                          ← appPackageName = "MyApp_1.0"
│   ├── 1_Setup\Setup.exe               ← 安装入口
│   ├── 2_双击导入.reg                  ← 破解/授权（可选）
│   └── 4_授权文件\...                  ← 覆盖文件（可选）
└── CAD_2025\                           ← 另一个 appPackageName
    └── 1_Setup\...
```

`appPackageName` 可以写多个候选，用英文逗号分隔（例如 `CAD_2025,CAD2025`），客户端按顺序找第一个存在的。

## 三、脚本怎么写

脚本是逐行执行的 DSL，`//` 或 `#` 开头是注释。**第一行必须是校验头**。

### 3.1 校验头（第一行）

```
#filePath=1_Setup\Setup.exe;md5=<32位hex>;appName=MyApp;computer=strict;verify=<16位FVN1a>
```

| 键 | 作用 |
|---|---|
| `filePath` | 相对 `%RUN_PATH%`（安装包目录）的文件；有它才做校验 |
| `md5` | 该文件 MD5；**不匹配 → 这条任务被静默跳过**（客户端不报错） |
| `appName` | 去开始菜单找 `<appName>.lnk`，找到就弹"检测到已经安装软件"（防重复装） |
| `computer=strict` | 主机名含中文时弹警告（部分软件不支持中文计算机名） |
| `verify` | FNV1a 快速指纹（前 8KB）；和 md5 同时写会**再校验一次** |

> ⚠️ 三个坑：
> 1. **首字符会被吃掉**：引擎对第一行做 `Substring(1)`，所以首字符必须是 `#` 或 `/`，否则 `filePath` 会变成 `ilePath`。
> 2. **md5 写错 = 任务不执行**，而且没有任何提示，最容易踩。
> 3. 用记事本另存为 UTF-8 **带 BOM** 会把 BOM 塞进第一行，同样导致首字符错位——用 `new_task.py` 生成最稳。

### 3.2 可用变量

| 变量 | 含义 |
|---|---|
| `%RUN_PATH%` | 安装包目录（上面那个 `MyApp_1.0\`） |
| `%PATH%` | 安装目标目录（`SET_PATH` 设置，默认 `C:\MySoftware`） |
| `%DISK%` | 客户端界面上选的磁盘，如 `C:\` |
| `%TEMP%` | 系统临时目录（引擎自动注入） |
| `%APP_PATH%` | `APP_PATH 软件名` 查到的已安装目录 |

其它 `%XXX%` 不会被替换（会原样传下去），`new_task.py lint` 会警告。

### 3.3 四种常见模板

**MSI 静默安装**
```
#filePath=1_Setup\MyApp.msi;md5=...
SET_PATH 'Program Files\MyApp'
RUN_INFO 'msiexec.exe' '/i "%RUN_PATH%\1_Setup\MyApp.msi" INSTALLDIR="%PATH%" /qb /norestart /L*V "%TEMP%install_myapp.log"'
SLEEP 3000
PRINT 安装完成
```

**Setup.exe（InstallShield / NSIS 向导）** —— 靠控件 ID 点下一步
```
#filePath=1_Setup\Setup.exe;md5=...;appName=MyApp
SET_PATH 'Program Files\MyApp'
RUN_A 'start "" "%RUN_PATH%\1_Setup\Setup.exe"'
WHILE_WIN '安装 - MyApp' 60          # 等窗口出现（最多60秒）
SET_WIN '安装 - MyApp'               # 绑定窗口并枚举控件
WHILE_TEXT 许可证协议 60             # 等某个文本出现
CLICK 1000                           # 点"我接受"（控件ID见下方"抓控件"）
CLICK 1                              # 下一步
SET_TEXT 4 PATH                      # 路径框填 %PATH%
CLICK 1
SLEEP 40000
WHILE_TEXT 完成 200
CLICK 1
```

**绿色软件（解压即用）**
```
SET_PATH 'Program Files\MyApp'
COPY_FILES '%RUN_PATH%\Program' '%PATH%'
LINK 'MyApp'                          # 桌面建快捷方式
```

**导入注册表授权（需要先导 .reg 的那类）**
```
RUN '%RUN_PATH%\2_双击导入.reg'
SLEEP 1500
SET_WIN '注册表编辑器'
KEY ENTER
SLEEP 1000
SET_WIN '注册表编辑器'
KEY ENTER
SLEEP 1000
```

### 3.4 覆盖破解文件

```
COPY_FILES '%RUN_PATH%\4_授权文件\Program Files\MyApp' '%PATH%'   # 目录递归复制
FILE       '%RUN_PATH%\app.exe' '%PATH%\DemoApp'              # 单文件复制（第2参是目录！）
```

## 四、抓控件 ID（向导类安装包必用）

### 4.0 懒人版：WinSnap.exe（拖一下就出脚本片段）

`tools/WinSnap/WinSnap.exe` 双击打开 → 按住左键把十字准星**拖到安装窗口上松开**，它会：

- 递归枚举该窗口全部控件（层级 / 控件ID / 句柄 / 类名 / 文本）
- 勾"只看可交互控件"过滤掉静态文字
- 自动生成可直接粘进脚本的片段：

```
SET_WIN '安装 - MyApp'
CLICK_TEXT '我接受(I)'        # ID 1000
CLICK_TEXT '下一步(N)'        # ID 1
SET_TEXT 4 PATH               # 输入框(ID 4, 类 Edit)  ← 填安装路径
# CLICK_RELATIVE 420 260      # 我接受(I)
```

点"复制脚本片段"直接进剪贴板。另有两个入口：
`抓前台窗口(3秒后)`（先切到安装界面再等 3 秒），以及命令行
`WinSnap.exe /dump <进程名|PID>`（输出到控制台，方便批量/自动化）。

### 4.1 手动版（客户端 F12 调试控制台）

1. 客户端启动后按 **F12** 打开"调试信息"控制台（或授权码用户名是 `admin` 时自动弹出）。
2. 脚本里先 `SET_WIN '窗口标题'`，再 `GET_CODE` 或 `WIN_INFO`，控制台会打印：
   ```
   层级2-ID:1000-句柄:0x00123456-类:Button-文本:我接受(I)
   层级2-ID:4-句柄:0x00123478-类:Edit-文本:
   ```
3. 把 ID 写进 `CLICK 1000` / `SET_TEXT 4 PATH`。
4. `CLICK_TEXT 我接受` 可以按文案点（比 ID 稳，跨版本不易变）。

## 五、用工具生成 + 校验 + 推送（推荐）

```bash
# 看现有任务
python new_task.py list   --server http://YOUR_HOST --token 口令

# 生成并预览（不推送）：自动找入口、算 MD5/指纹、跑语法校验
python new_task.py make --dir "D:\装机包\MyApp_1.0" --name MyApp --ver 1.0 --firm 某某公司 \
                        --template msi --entry "1_Setup\MyApp.msi" --dry-run

# 生成 + 校验 + 直接推到服务器
python new_task.py make --dir "D:\装机包\MyApp_1.0" --name MyApp --ver 1.0 \
                        --template setup --entry "1_Setup\Setup.exe" \
                        --extra "COPY_FILES '%RUN_PATH%\4_授权文件' '%PATH%'" \
                        --server http://YOUR_HOST --token 口令

# 校验一份手写脚本
python new_task.py lint --script my_app.txt

# 删任务
python new_task.py delete --id 54 --server http://YOUR_HOST --token 口令
```

`lint` 会抓：未知命令（比如把 `PRINT` 写成 `PRING`）、变量拼错（`%PAT%`）、缺参数、校验头首字符错位。

## 六、上线前检查清单

1. `new_task.py lint` 通过（0 错误）。
2. 目标机器上把 `appPackageName` 目录和 exe 放好，exe 启动后能看到"安装：xxx"。
3. 输授权码 → 开始 → 观察客户端界面进度 + F12 调试控制台的逐条输出。
4. 装完去管理台 **安装上报** 看这条记录：`other` 字段里是完整逐条日志，`recordId` 是入库序号。
5. 失败常见原因：md5 不匹配（任务被跳过）、控件 ID 变了（用 `CLICK_TEXT` 按文案点）、
   窗口标题带版本号（`WHILE_WIN '安装 - MyApp 1.0'` 注意大小写/全角）、
   安装包需要交互但没 `SET_TEXT` 填路径。
